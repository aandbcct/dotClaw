# dotClaw 前端补齐与视觉改造开发说明

方案日期：2026-10-22｜实施验收：2026-10-23｜分支：`feat/gui`，包括当前未提交改动

## 1. 本轮结论与范围

**本轮做已有能力的 Web 接入和前端体验改造，不新增核心 AI 能力。** 可以立即安排：会话切模型、删除会话、历史正文搜索、历史执行记录、已有搜索结果展示，以及直接开始聊天、导出、浏览器置顶、生成中切换会话、阅读体验和视觉改版。

修正上一版建议：**编辑后重生成、自动重试、上传文件、成果文件管理、配置热更新不应列为“补接口即可”。** 它们需要新的历史、运行、资源或配置生命周期机制。本轮不放对应的占位按钮。

核对依据为当前源码，以及实际打开的 `http://127.0.0.1:5173/` 聊天页和设置页；底层能力已确认存在，不代表所有真实模型、搜索凭证已联调通过。第 3–7 节保留实施契约，“新增”表示相对原前端基线增加；最终实现、验收证据与限制见第 9 节。视觉方案是设计判断，尺寸为本项目规格，不是 ChatGPT 的原始参数。

## 2. 明确区分三类工作

### A：补接口/数据投影即可，不新增核心能力

| 编号 | 可交付功能 | 已有依据 | 尚需工作 |
|---|---|---|---|
| A1 | 当前会话切换已配置模型 | `SessionInteractionService`（会话交互服务）的 `switch_model()` 已校验模型并持久化；后续运行冻结模型选择 | Web 接口、执行租约保护、顶部选择器 |
| A2 | 完整删除会话 | 同一服务的 `delete_session()` 已检查未结束运行、清理审批、会话目录和上下文缓存 | Web 接口、并发入口保护、删除确认和列表更新 |
| A3 | 搜索历史正文并跳转 | `SessionManager`（会话持久化管理器）的 `list_all()` 已返回完整会话；记录包含问题、回答、稳定 ID | 只读过滤接口、搜索弹窗、命中定位；先顺序扫描，不建新检索系统 |
| A4 | 查看每轮历史执行记录 | 每轮记录已有 `agent_run_ids`；现有 activity 接口支持指定 `run_id`，已有运行证据查询 | 在历史消息中投影运行 ID；逐轮入口、详情抽屉 |
| A5 | 已执行搜索的结果列表 | `builtin.web.search` 已输出 `query/results/title/url/snippet`；activity 已暴露工具结果 | 解析已知结果格式并展示来源；不新增搜索执行入口、不保证每条回答都会调用搜索 |

A 类允许补必要的应用层并发保护和只读查询，不更改推理、工具执行或历史压缩算法。并不是“写一条路由就结束”。

### B：前端即可或主要是前端，不必新增接口

| 编号 | 本轮能做 | 明确交付边界 |
|---|---|---|
| B1 | 无会话时直接输入，首次发送自动建会话 | 复用 options、创建、发送接口；高级选择仍可打开 |
| B2 | Markdown 导出 | 导出已完成历史正文和标题/模型信息；不是导出运行事实、附件或完整备份 |
| B3 | 置顶、最近会话恢复、侧栏折叠 | 浏览器偏好；只在当前浏览器持久化，不宣称跨设备同步 |
| B4 | 同一页面生成中切会话并继续阅读 | 按会话保留现有流连接；刷新后只能恢复状态并在完成后取最终回答，不能承诺找回丢失的逐字增量 |
| B5 | 公式、长代码折叠、现有图片放大、输入与阅读优化 | 内容渲染能力；图片放大不等于支持图片上传/识图 |
| B6 | 聊天页、设置页、执行详情的视觉改版 | 接口和既有审批/恢复语义保持一致；按第 5 节实施 |

### C：要补核心机制，本轮不做

| 能力 | 为什么不是接接口 | 本轮可保留的现有能力 |
|---|---|---|
| 编辑历史问题、重新生成、答案版本切换、分支 | 现有历史为线性追加，且有版本号和历史压缩边界；删除最后一条再提交会破坏历史一致性。工具再次执行还可能重复产生副作用 | 复制到输入框后作为新问题发送；按钮写“引用到输入框”，不能叫“重生成” |
| 自动失败重试 | HTTP 断开不代表任务失败；缺少此次发送的去重/重放协议，重复提交可能重复执行工具 | 查运行状态；已支持的恢复/审批/取消 |
| 刷新后逐字续流 | 当前流没有可重订阅的事件游标与增量重放；运行事实不等于全部 token 增量 | 状态轮询与最终回答回填 |
| 上传文件、截图识别 | 缺附件资源、解析、会话绑定、多模态输入契约 | 纯文本输入、已有 Markdown 图片显示 |
| 成果文件下载/预览工作区 | 本地文件工具不等于受控成果协议；缺文件归属、可下载资源标识和生命周期 | 导出当前对话 Markdown |
| 强制联网模式、逐句引用校验 | 已有搜索工具不等于每次请求的工具策略；来源列表不等于答案每句话的证据映射 | 已执行搜索的来源展示（A5） |
| 网页新增模型提供方、修改运行参数、MCP 增删改并立即生效 | 已有配置加载，但未见统一编辑/验证/重建依赖/失败回滚流程；只写配置文件不代表运行进程已采用 | 查看配置、已有工具/技能开关、已有 MCP 重连 |
| 项目空间、记忆编辑删除/总开关、临时聊天、自定义指令管理 | 缺项目隔离和管理接口；记忆是源文件加索引，直接删索引可能再次同步回来；临时会话需定义所有持久化路径 | 现有智能体选择、已有记忆检索能力继续使用 |
| 语音、图像生成、可编辑画布、专用数据分析工作区、在线分享 | 需要媒体服务、资源协议、执行环境或身份访问控制。已有命令执行不代表完整分析产品 | 暂不展示入口 |

## 3. A 类开发任务：接口契约、前端交互与验收

### A1：会话内切换模型

**新增** `PATCH /api/v1/sessions/{session_id}/model`，请求 `{"model":"已配置模型名"}`，成功 `200` 返回现有会话摘要结构。使用独立路由，避免一次请求混合改名、归档、切模型造成部分成功。

后端要求：

- 候选来自现有 `/api/v1/options` 的模型列表，不使用设置页全部模型（其中可能包含向量模型）。
- 在应用层对目标会话取得 `edit_session()` 租约，再重读并调用已有切模型方法。当前 `switch_model()` 本身没有租约，不能直接暴露后让运行投影覆盖设置。
- 会话不存在 `404`；空值/未知或禁用模型 `422`；执行中 `409 session_busy`。沿用现有 `error.code/message` 错误结构，不能把所有校验错误都翻译成“会话忙”。
- 已挂起运行保持冻结的原模型；选择器旁说明“用于后续新消息”。不迁移当前运行或修改旧回答的模型归属。

前端要求：顶部显示可点击的模型名称与下拉箭头；成功后更新会话摘要，失败保留原值和下拉选择。运行时禁用该会话的切换入口；服务端仍需校验来自其他标签页的请求。

验收：切换后刷新仍保留；下一轮使用新模型；已有运行不变；未知模型不落盘；切换与消息完成同时发生不丢历史；其他会话不受影响。

### A2：删除完整会话

**新增** `DELETE /api/v1/sessions/{session_id}`，成功和已不存在均 `204`；目标会话仍有非终态运行返回 `409 session_busy`。

后端必须调用应用层 `delete_session()`，不能直接调用磁盘删除。将删除与同会话提交/元数据修改放入同一租约边界，重新确认活动状态后再清理，避免“检查时空闲、删除时刚开始运行”。保留已有审批与缓存清理；增加租约时避免嵌套获取同一把锁。

前端入口放在会话“更多”菜单底部。确认框写明“删除‘标题’及其运行记录，无法恢复”，默认焦点在取消。仅服务端成功后移除列表、清理该会话草稿和本机置顶项；删除当前会话后进入新对话空白页。遇到 `409` 引导用户打开该会话处理运行，不自动停止或强删。

注意 `api.ts` 的现有 JSON 请求函数会直接执行 `response.json()`；DELETE 的 `204` 必须走无响应体分支。

验收：普通/归档会话可删除；重复删除成功；运行中、等待审批、可恢复状态被拒绝；错误时列表不消失；删除后刷新不复现；其他会话和共享智能体缓存不受影响。

### A3：全文搜索与定位

**新增** `GET /api/v1/sessions/search?q=关键词&archived=all&limit=30`。静态路由放在 `/sessions/{session_id}` 之前，避免将 `search` 当 ID。

建议响应：

```json
{"items":[{"session_id":"...","title":"...","updated_at":"...","archived":false,"message_id":"...:assistant","role":"assistant","snippet":"包含关键词的原文片段"}],"has_more":false}
```

- `q` 去首尾空白，1–100 字符；`limit` 1–50；`archived` 为 `all/true/false`，非法参数 `422`。
- 调用已有 `list_all()`，对标题、问题、最终回答做不区分大小写的字面包含匹配；按会话更新时间降序、同会话按历史顺序返回。每条匹配消息一项；只命中标题时 `message_id/role` 为 null。
- 截取命中点前后约 80 字作为纯文本；不返回整段历史、不解释为 HTML。总结果截断时 `has_more=true`，提示缩小关键词；首版不做向量检索/排名索引。
- 前端统一入口“搜索对话”，弹窗输入后 250ms 防抖；废弃过期请求响应。结果显示标题、正文片段、归档标签。
- 点击后读取完整会话，按现有消息 ID 定位并短暂高亮。归档命中可以查看，不自动取消归档。清空查询、无结果、请求失败分别呈现。

验收：中文、英文大小写、只在回答出现的关键词、归档会话均可命中；连续输入不会被旧响应覆盖；两条相似消息能准确跳转；输入 `<script>` 仅作为文本。

### A4：历史执行记录归到每轮回答

扩展现有会话详情的助手消息，增加 `run_ids: string[]`，来自该轮 `agent_run_ids`；旧记录无运行时返回空数组。不要依赖当前页面只保存的“最新运行 ID”。

点击回答下的“执行记录”，选定该轮运行后调用**已有** `GET /api/v1/sessions/{session_id}/activity?run_id=...`。多个运行时展示简短列表再选详情；已有数据只支持运行 ID 列表，首版不虚构完整父子任务树。

右侧抽屉展示状态、工具名、开始/结束时间、参数、结果和错误。历史终态仅供查看；当前待审批/恢复的按钮仍绑定真实运行。确认指定运行属于该会话，不接受跨会话拼接 ID 获取证据。

验收：打开旧会话，前两轮各自显示自己的记录；无工具的回答不出现空工具列表；有多个运行时能分别查看；关闭详情不停止运行；旧接口字段仍兼容。

### A5：搜索结果来源展示

复用 A4 的工具记录，只有 `name === "builtin.web.search"` 且结果成功时按 JSON 解析 `results`。有效条目要求标题和 `http/https` URL；摘要可选。保留原始结果折叠入口，解析失败回退原文，不能导致整条消息渲染失败。

回答下显示“搜索结果 · N 条”，点击展开标题、域名和摘要；按 URL 去重，保留原顺序。不渲染外部 HTML，不执行 `javascript:` 链接；新标签打开加 `noopener noreferrer`。

文案使用“搜索结果”，**不写“此答案已验证”**，不自动给正文插入无法对应的编号引用。搜索没有运行就不显示来源块，也不在浏览器直连搜索提供方。真实联网验收需要现有服务配置有效。

验收：使用已知成功/空结果/非法 JSON/非 HTTP 链接夹具验证；历史回答来源与对应运行一致；失败结果仍可查看错误。

## 4. B 类开发任务：复用现有接口

### B1：直接开始对话

新对话先显示本地空白输入页，不立刻建空会话。首次发送：读取默认选项 → 创建会话 → 用返回 ID 提交原始文本。高级按钮仍可选择已注册智能体和模型。

创建成功但发送失败时复用刚建的会话；不要再次创建。发送过程中防重复点击。将新 ID 显式传给提交逻辑，不依赖刚调用状态更新后立即读取旧的选中会话。输入在确认发起发送前不得丢失；网络结果不明时提示查看运行状态，不自动重发。保留输入法组合输入与 Shift+Enter 行为。

验收：首条消息只建一个会话、只发一次；无可用模型时给出清晰原因；创建失败保留输入；高级选择仍可用。

### B2/B3：导出和本机组织

- “导出 Markdown”放会话更多菜单，读取完整已完成历史生成 UTF-8 `.md`；包含标题、导出时间、当前会话模型、按角色分隔的原始文本。说明当前模型不是每条旧回答的模型。生成中导出标注“仅包含已完成记录”。清理文件名非法字符，释放下载对象 URL。
- 置顶存 `localStorage` 的独立版本化键，只存会话 ID；不调用会话保存，避免改变更新时间。已删除 ID 过滤掉；归档会话只在归档视图出现，恢复后再按置顶偏好排序。
- 侧栏折叠状态、最近打开会话也只存本机。存储不可用时当前页面仍能用，不能因此阻止打开会话。

验收：代码缩进、中文、表格原文导出正确；刷新保留本机偏好；恢复归档与删除后的排序正确；导出不包含密钥或工具原始参数。

### B4：运行期间切会话，限定为当前页面生命周期

这是前端状态改造，工作量高于简单按钮接线，但不需要新推理能力。

- 将 `messages/runPhase/runActivity/error/currentRunId` 按会话 ID 保存；流控制器也按会话保存。回调闭包固定会话 ID，只更新所属条目，不能引用当时选中的会话。
- 页面切换不关闭后台会话流；只在页面卸载时清理订阅。停止按钮只操作当前会话。
- 新建与切换不再被全局运行状态锁死。每个会话仍只能提交一个有效运行，保留后端忙状态约束。
- 轮询仅覆盖当前页面已知仍活动的会话；终态停止，切换时不重复启动轮询。异步历史刷新必须更新对应会话，不能把后台会话强行选中。
- 刷新页面后通过现有 activity 恢复状态。正文增量暂不可恢复时显示“任务仍在运行，完成后显示结果”；终态后加载完整会话。不能显示“流式已恢复”。

验收：A 会话生成时切到 B，B 不收到 A 的字；切回 A 能看到当前页面累计文本；A 完成不抢走 B 的焦点；停止 B 不取消 A；刷新后不重复发送。覆盖失败、取消、等待审批和恢复状态。

### B5：阅读体验

在现有 Markdown 渲染链中接公式插件（建议 `remark-math` + `rehype-katex` 与 KaTeX 样式），保留默认原始 HTML 隔离；测试行内/块级公式与代码中的美元符号。插件版本在实施时按当前依赖验证，不固定猜测版本。

长代码初始最大高度 360px，显式展开/收起，复制始终复制完整代码；已有 Markdown 图片点击放大，Esc 关闭且焦点返回；表格横向滚动保持在消息内部。流式新增内容时，用户正在上翻就不强制滚到底部。

## 5. 视觉改造：开发必须按区域落实

### 5.1 当前问题与设计方向

已观察：聊天页侧栏每条会话常驻标题、模型、日期、重命名、归档，多条记录很快占满；设置页每个模型都是大面积带底色卡片，内部却用 10–11px 小字承载多个标签；聊天页顶部、作者时间、底部提示不断重复辅助信息。

**设计判断：现有颜色已经统一，主要缺少主次取舍。** 不建议加渐变、插画或更多卡片。方向定为“中性、安静、正文优先的本地聊天工作区”：中性白/灰为主，保留低饱和绿用于品牌与焦点，依靠字号、间距和操作收纳建立层级。

视觉优先级：回答正文与输入框 > 当前会话/模型 > 导航 > 时间、运行 ID、配置技术字段。界面不添加营销口号。默认工作面只有侧栏和聊天区；执行详情按需打开。

### 5.2 布局规格

| 区域 | 桌面 ≥1024px | 窄屏 768–1023px | 手机 <768px |
|---|---|---|---|
| 导航 | 默认宽 248px，可折叠为 56px 图标栏 | 默认 56px，可展开覆盖 | 默认隐藏，280px 或 86vw 抽屉 |
| 顶栏 | 高 56px，左右 24px | 高 56px，左右 20px | 高 52px，左右 12px |
| 正文/输入对齐 | 共用最大宽 760px，最小左右边距 24px | 左右 20px | 左右 16px |
| 执行抽屉 | 宽 360px；宽屏可占布局列 | 盖在工作区上，保留关闭入口 | 全屏详情层 |
| 设置 | 最大宽 880px，最大高 `calc(100dvh - 64px)` | 宽 `calc(100% - 40px)` | 全屏；分类可横向滚动 |

### 5.4 侧栏怎么改

1. 顶部缩为单行品牌与折叠按钮；移除常驻副标题。新对话为高度 40px 的轻按钮，不做大号白色卡片。
2. 搜索改为一行入口，点击打开 A3 弹窗；不再占据一整个输入框加额外筛选条的高度。
3. 会话行只显示单行标题；标题过长省略，悬停或焦点时可查看完整标题。模型移到顶部选择器；日期通过“今天/最近 7 天/更早”分组表达，不逐行重复。
4. 重命名、归档/恢复、置顶、导出、删除收进 `⋯` 菜单。桌面 hover 或 `focus-within` 出现，手机和键盘聚焦时始终可访问；不要只有鼠标才能操作。
5. “已归档”保留明确入口，设置固定底部。移除占大块区域的本机状态卡，将部署说明放设置“关于”。“数据保留在本地”不能暗示远程模型请求不发送内容。
6. 运行中的会话以小状态点加可访问文本表示，选中态用底色+字重，不使用脉冲动画吸引全局注意。

### 5.5 顶栏、消息和输入框怎么改

- 顶部左侧突出模型选择器；会话标题次级展示，右侧放更多菜单。智能体信息收进选择器详情。只有运行/等待审批/异常时显示状态，“就绪”不常驻。
- 用户消息右对齐、浅灰底，最大宽正文的 80%；助手回答左对齐且不加气泡容器。正文保持同一阅读左边界。
- 默认隐藏逐条时间，放详情或悬停提示；不要每条回答重复醒目的绿色作者名。消息操作可低对比显示，焦点/悬停时增强，复制反馈不改变按钮宽度。
- 工具执行默认是一条状态摘要；展开进入 A4。**待审批不能藏到抽屉里**：正文保留明显的审批提示和“查看并决定”入口，抽屉中确认参数再批准。
- 新对话页显示一句“有什么可以帮你？”与可直接输入的输入框；不要再让用户先点击“创建第一个会话”。空白页可让输入框居中，发出第一条消息后放底部，避免夸张布局动画。
- 输入框默认约 76px，高度随文本增长到 200px 再内部滚动；发送/停止按钮视觉 36px，触摸命中区至少 44px。当前不放附件、麦克风、强制搜索按钮。
- 去掉“草稿自动保存”的长期说明；保存失败才显示提示。桌面快捷键提示用一行低调文字，手机不显示 Enter 说明。
- 错误贴近发生动作：模型失败在选择器旁，发送失败在输入框上方，配置读取失败在设置页内。不要为了设置请求错误直接关闭设置弹窗。

### 5.6 设置与执行详情怎么改

- 设置标题仅“设置”，去掉 `WORKSPACE` 装饰标题。左分类宽 160px，右内容左右间距 24px。
- 模型展示改为紧凑列表：名称、用途、默认标识为首行；提供方和模型 ID 为次行；点击展开上下文长度等技术信息。区分“对话模型/向量模型”，后者不能作为聊天候选。
- 不把 `active` 显示成“连接正常”；它只代表配置启用。中文文案“已启用”“密钥已配置”保留真实含义。
- 工具/技能采用分隔列表：左标题+一行摘要，右开关；更多描述展开。列表顶部本地过滤输入，避免长列表只能滚动查找。
- 模型和运行参数本轮仍只读，标题旁标“只读”，说明需修改本地配置并重启；不要摆出保存按钮制造可编辑假象。已有工具/技能开关和 MCP 重连继续可用。
- 执行详情用纵向步骤列表；名称/状态先展示，参数和结果默认收起，原始 JSON 仅占展开区域。错误原因靠近失败步骤，运行 ID 放页脚可复制。
- 所有弹层 Esc 关闭、焦点限制在弹层、关闭后回到触发按钮；背景不可误点击。手机详情页保留清楚的返回入口。

### 5.7 动效与可访问性

仅保留菜单淡入 120–160ms、抽屉 180–220ms、按钮状态过渡约 120ms；尊重减少动态效果设置。消息逐字增长不反复播放整块入场动画。

普通文本对比度至少 4.5:1，大字至少 3:1；必要的控件边界/焦点可辨识。WCAG 2.2 的最小目标有 24px 及间距例外，本项目触摸控件统一按 44px 命中区设计。200% 缩放仍可操作；表格/代码局部横滚，页面整体不横向溢出。

### 9.3 根据源码调整的实现细节

- **租约属于应用服务。** `switch_model()` 与 `delete_session()` 自身取得编辑租约，HTTP 层只作契约转换。切模型重读最新会话，旧对象不能覆盖刚完成的历史。删除保留原有审批、运行和缓存清理。
- **删除/提交竞态不能在租约外先读文件。** Windows 并发测试暴露文件读句柄与删除冲突；提交逻辑改为租约内准备请求，HTTP 预检只检查路径存在。`SessionManager`（会话持久化管理器）增加无打开文件句柄的 `exists()`；最终业务判断仍在应用服务内。相关假服务补齐方法，测试不绕过租约。
- **搜索复用完整会话读取。** 首版顺序扫描，限制的是返回结果而非磁盘扫描量；没有新索引、向量检索或排名系统。
- **设置复用现有接口。** 模型/运行配置明确只读；运行配置展示不保证每个现有字段都被当前执行链消费。工具/技能开关与 MCP 重连保留真实接口；配置启用不写成连接正常。
- **统一弹层交互。** 更多操作、搜索、设置、图片预览与执行详情复用原生模态弹层，低频菜单不是全套第三方 UI 框架；实现 Tab 循环、Esc、背景隔离、关闭焦点返回。历史详情与当前运行控制保持分离。
- **公式仅加对应依赖。** 增加 `remark-math`、`rehype-katex`、`katex`，用 npm override 统一 KaTeX 渲染/样式版本。保留原始 HTML 隔离，不允许受信任数学命令。
