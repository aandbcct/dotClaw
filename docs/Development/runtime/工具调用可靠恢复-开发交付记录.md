## 实施中明确的取舍

- 继续使用本地文件，单宿主进程写入，每运行一个驱动、一个待补写工具投影；没有引入 SQLite、并发工具调度或存储插件体系。
- 外部副作用与未知工具默认不自动重试。安全恢复要求冻结契约与作用域有效；重试次数取当前与冻结上限的较小值，退避参数变动保守阻断。
- 新增 `execution_scope` 保存规范化的工作目录与权限范围。旧空值不能授予安全重试；本轮不实现权限集合包含关系算法。
- 未知效果不能伪装成确定业务失败。不可安全恢复时停止运行并提示外部操作可能已经生效；外部查询与受限 Agent 调查后置到 Issue #52。
- 失败结果保存与整次运行停止策略已经分开；本轮仍保留普通工具失败停止行为，失败回灌模型后置。
- 新内置声明使用函数参数，旧自定义工具显式 `args_model` 保留兼容。恢复元数据与注入上下文不进入模型业务参数。
